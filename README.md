# Cricket Chronicles: A Collection of Books on the World of Cricket Information Organization System
A Fall Semester Project in UNT

"Cricket Chronicles" is an information organization system designed to catalog and manage literature related to cricket. The project aimed to help cricket enthusiasts easily search and access content such as player stories, game strategies, and historical data. It applied traditional library science principles to a specialized domain, making it unique. The biggest challenges involved handling diverse types of content and ensuring accurate, up-to-date information. The creator also reflected on improving user experience in future versions by adding personalized recommendations and interactive features.
